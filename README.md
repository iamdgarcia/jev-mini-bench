# ⚡ Jev Mini Bench
**▶ Try it live:** <https://iamdgarcia-jev-mini-bench.static.hf.space> · **Code on GitHub:** <https://github.com/iamdgarcia/jev-mini-bench>


The decision-model wave, in your pocket. TypeSafe's **Jev** showed a tiny model can route a
support conversation with a single yes/no decision — dozens of open repros followed
(kev, tev, gev, lev, clef…). This mobile-first mini bench lets you **feel the latency gap**
(~1200 ms big-LLM vs ~12 ms tiny decision model), try an honest **demo heuristic router**
(EN/ES), and **vote** for your favorite community repro.

🔗 Full benchmarks & news: [jev-decision-index](https://huggingface.co/spaces/multimodalart/jev-decision-index)

Built by [iamdgarcia](https://huggingface.co/iamdgarcia) — realtime voice agent engineer.
